# Example 00

Descrição
---------

Exemplo mínimo de aplicação Node.js incluída neste repositório para demonstrar a estrutura básica de um projeto. Contém um ponto de entrada simples em `index.js` e o manifesto do projeto em `package.json`.

Requisitos
---------

- Node.js v22 (necessário)
- npm (geralmente incluído com Node.js)

Como executar
--------------

1. Instale dependências:

```bash
npm install
```

2. Execute a aplicação:

```bash
node index.js
```

Caso o `package.json` contenha um script `start`, você também pode usar:

```bash
npm start
```

Estrutura
---------

- `index.js` — ponto de entrada da aplicação
- `package.json` — dependências e scripts

Observações
---------

Este é um exemplo simples; adapte-o conforme necessário para seu projeto. Se precisar, posso adicionar instruções mais detalhadas ou exemplos de uso.
